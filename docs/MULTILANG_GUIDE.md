# Multi-Language Code Generation Guide

## Quick Start

### Option 1: Full Workflow (Recommended)
```powershell
# Parse LeetCode problem AND generate solutions in all languages
python run_multilang.py full sample_leetcode.txt --llm gemini --api-key YOUR_KEY
```

### Option 2: Step-by-Step

#### Step 1: Parse LeetCode Problem
```powershell
# From file
python run_multilang.py parse sample_leetcode.txt

# From clipboard (copy problem, then paste)
python run_multilang.py parse -
```

This creates task JSON files:
- `tasks/two_sum_python.json`
- `tasks/two_sum_cpp.json`
- `tasks/two_sum_java.json`
- `tasks/two_sum_javascript.json`

#### Step 2: Generate Solutions
```powershell
python run_multilang.py generate tasks/two_sum_python.json --llm gemini --api-key YOUR_KEY
```

## LeetCode Problem Format

Copy the entire problem text including:
- Title
- Description
- Examples (Input/Output)
- Constraints
- Time/Space complexity requirements

Example:
```
Two Sum

Given an array of integers nums and an integer target...

Example 1:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]

Constraints:
- 2 <= nums.length <= 10^4

Time Complexity: O(n)
Space Complexity: O(n)
```

## Advanced Usage

### Generate Specific Languages Only
```powershell
python run_multilang.py full problem.txt --languages python cpp --llm gemini --api-key KEY
```

### Use Different LLM Providers
```powershell
# Mock (for testing)
python run_multilang.py full problem.txt --llm mock

# OpenAI
python run_multilang.py full problem.txt --llm openai --api-key OPENAI_KEY

# Anthropic
python run_multilang.py full problem.txt --llm anthropic --api-key ANTHROPIC_KEY
```

### Customize Output Directories
```powershell
python run_multilang.py parse problem.txt --output-dir my_tasks
python run_multilang.py generate task.json --output-dir my_solutions
```

## Understanding the Output

### Solution Files
Each solution file includes:
```python
"""
Problem: Two Sum
Algorithm: Hash Table
Time Complexity: O(n)
Space Complexity: O(n)
Generated by: CodeSmith Multi-Language Generator
"""

# Actual solution code...
```

### Algorithm Detection
The system automatically identifies:
- **Hash Table**: Using dict/map/HashMap
- **Binary Search**: Sorted array search
- **Two Pointers**: Left/right pointer technique
- **Dynamic Programming**: Memoization/tabulation
- **Sliding Window**: Substring/subarray problems
- **Graph Traversal**: BFS/DFS
- **Greedy**: Optimal choice at each step
- **Divide and Conquer**: Recursive splitting

### Complexity Extraction
Automatically parses:
- Time: `O(n)`, `O(log n)`, `O(n²)`, etc.
- Space: `O(1)`, `O(n)`, `O(log n)`, etc.

## Troubleshooting

### Error: "No API key provided"
```powershell
# Set environment variable
$env:GEMINI_API_KEY="your-key-here"
python run_multilang.py full problem.txt --llm gemini

# Or pass directly
python run_multilang.py full problem.txt --llm gemini --api-key YOUR_KEY
```

### Error: "Failed to parse problem"
Make sure your problem text includes:
- Clear title at the top
- Examples with "Input:" and "Output:"
- Constraints section

### Error: "Code generation failed"
- Check internet connection (needs API access)
- Verify API key is valid
- Try `--max-attempts 5` for more retries

## Tips for Best Results

1. **Copy Complete Problems**: Include all examples and constraints
2. **Use Gemini for Speed**: Fastest and most cost-effective
3. **Review Python First**: Most thoroughly tested
4. **Check Complexity Claims**: LLM-detected, may need verification
5. **Custom Test Cases**: Edit task JSON to add your own tests

## Integration with Existing Tasks

You can also use existing CodeSmith task files:
```powershell
python run_multilang.py generate examples/tasks/Two_sum.json --llm gemini --api-key KEY
```

This generates C++, Java, and JavaScript versions of existing Python tasks!

## Batch Processing

Process multiple problems:
```powershell
# Parse all problems
python run_multilang.py parse problem1.txt --output-dir tasks
python run_multilang.py parse problem2.txt --output-dir tasks
python run_multilang.py parse problem3.txt --output-dir tasks

# Generate all solutions
Get-ChildItem tasks\*_python.json | ForEach-Object {
    python run_multilang.py generate $_.FullName --llm gemini --api-key KEY
}
```
