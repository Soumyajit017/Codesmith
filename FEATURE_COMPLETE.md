## Example: Two Sum Problem

### Input (LeetCode Problem)
```
Two Sum

Given an array of integers nums and an integer target, 
return indices of the two numbers such that they add up to target.

Example 1:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]

Time Complexity: O(n)
Space Complexity: O(n)
```

### Command
```powershell
python run_multilang.py full two_sum.txt --llm gemini --api-key YOUR_KEY
```

### Output Files
```
tasks/two_sum_python.json      - Python task spec
tasks/two_sum_cpp.json         - C++ task spec  
tasks/two_sum_java.json        - Java task spec
tasks/two_sum_javascript.json  - JavaScript task spec

solutions/two_sum/
├── solution.py                - Python with hash table
├── solution.cpp               - C++ with unordered_map
├── solution.java              - Java with HashMap
└── solution.js                - JavaScript with Map
```

### Generated Python Solution
```python
"""
Problem: Two Sum
Algorithm: Hash Table
Time Complexity: O(n)
Space Complexity: O(n)
Generated by: CodeSmith Multi-Language Generator
"""

import sys

def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

if __name__ == '__main__':
    nums = list(map(int, sys.stdin.readline().strip().split(',')))
    target = int(sys.stdin.readline().strip())
    result = two_sum(nums, target)
    print(' '.join(map(str, result)))
```
